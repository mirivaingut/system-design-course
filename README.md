# מסע ל-System Design

קורס אישי של כחמישה שבועות: 18 שיעורים, 113 שאלות עם הסבר לכל אפשרות, 14 סימולציות, 155 מושגים במילון, 5 תרגילי תכנון מלאים ו-8 תבניות.
הסיפור שמלווה את כל הקורס: אפליקציית הצ'אט "שיחון".

## מה יש באתר

- **מפת המסע**: 18 תחנות ב-5 שבועות (החמישי הוא העמקה), רמות (Junior עד Architect) ותגים.
- **שיעור**: חימום (חזרה מרווחת: שאלות שטעית בהן או ניחשת חוזרות יותר), משבר, הסבר עם אנלוגיות ופינת "מהעולם שלך: Java/Spring/React", סימולציה, Trade-offs, "לדבר כמו ארכיטקטית", תרגיל תכנון עם רמזים ופתרון, בוחן, ו-Design Review בסוף כל שבוע. בפתיחה: "מה את היית עושה?" לפני ההסבר. בסוף: משימות בשטח במערכת שלך, ומקורות לקריאה נוספת.
- **שאלות**: בוחרים תשובה ומסמנים כמה את בטוחה. אחר כך אפשר לבקש רמז, להציג את התשובה ואת ההסבר לכל אפשרות, או ליצור פרומפט לקלוד על השאלה.
- **תרגול**: 5 מערכות חדשות (מקצר קישורים, פיד, סנכרון קבצים, מעקב שליחים, יומן ביקורת), צעד אחרי צעד, עם "מה מצופה בכל רמה", טעויות נפוצות ופרומפט לביקורת של Claude על התשובות.
- **תבניות**: 8 בעיות חוזרות (הגדלת קריאות וכתיבות, זמן אמת, התנגשויות, משימות ארוכות, תהליכים מרובי שלבים, קבצים, עמידות), ובוחן זיהוי.
- **דף שליפה**: ברירות מחדל בטוחות, טעויות נפוצות, והשאלות ששואלים בכל דיון.
- **מילון**: כל מושג בשיעור מסומן בקו מקווקו. מעבר עם העכבר מציג הסבר קצר, ולחיצה מעבירה למילון.
- **המאגר שלי**: מסמנים טקסט בשיעור ולוחצים על "➕ הוספה למאגר שלי". משם יוצרים פרומפט מסודר לקלוד מכל הפריטים ומהשאלות שהיו קשות.
- **הורדת שיעור**: קובץ HTML עצמאי (נפתח בכל דפדפן, גם בלי אינטרנט) עם התשובות, הפתרונות, מילון המונחים של השיעור והתכנון שכתבת. יש גם הדפסה ל-PDF.
- **סנכרון וגיבוי**: עם קוד הגישה, ההתקדמות מסונכרנת לענן בין מחשבים. גם בלעדיו, הכל נשמר בדפדפן, ואפשר לייצא ולייבא קובץ גיבוי.
- **תזכורות במייל**: כל X ימים או בימים קבועים, בשעה שבוחרים (שעון ישראל). "התגעגענו" אחרי X ימים בלי כניסה. לכל היותר מייל אחד ביום.

## ארכיטקטורה (כולה בחינם)

```
Cloudflare Worker (אחד)
 ├─ public/          האתר (HTML/CSS/JS סטטי, בלי build)
 ├─ /api/*           מוגן בקוד גישה (Bearer token, השוואה בזמן קבוע)
 │    state · visit · settings · test-email
 ├─ KV               התקדמות, מאגר, הגדרות, זמן ביקור אחרון
 └─ Cron כל שעה      מחליט אם לשלוח תזכורת או "התגעגענו" → Resend
```

Cloudflare Workers בתוכנית החינמית: 100K בקשות ביום, KV, Cron. השירות לא "נרדם" כמו שירותים חינמיים אחרים.
Resend בתוכנית החינמית: 3,000 מיילים בחודש.
אבטחה: כל האתר נעול בקוד כניסה. אחרי הכניסה נשמרת עוגיית סשן חתומה (HMAC, ‏HttpOnly, ‏Secure), ל-30 יום או ל-12 שעות במחשב משותף. אחרי 8 ניסיונות כושלים מאותה כתובת IP הכניסה ננעלת ל-15 דקות. ובנוסף: HTTPS, ‏CSP קפדני ו-X-Frame-Options.

## התקנה (פעם אחת, כ-10 דקות)

**א. Cloudflare** (איפה שהאתר רץ)
1. נכנסים ל-https://dash.cloudflare.com/sign-up, ונרשמים עם מייל וסיסמה. לא צריך כרטיס אשראי.
2. מאשרים את המייל שנשלח.
3. בתפריט בצד: **Workers & Pages**. אם מופיעה בקשה לבחור שם לתת-דומיין (subdomain), בוחרים שם קצר, למשל השם שלך. זה יהיה חלק מכתובת האתר.

**ב. Resend** (שליחת התזכורות)
1. נכנסים ל-https://resend.com ← **Sign up**, **עם הכתובת שאליה רוצים לקבל תזכורות**. (בלי דומיין משלך, Resend שולח רק לכתובת הזו, וזה בדיוק מה שצריך.)
2. מאשרים את המייל.
3. בתפריט: **API Keys** ← **Create API Key**. שם: `course`, הרשאה: **Sending access** ← Create.
4. מעתיקים את המפתח (מתחיל ב-`re_`). הוא מוצג **פעם אחת בלבד**.

**ג. העלאה**
1. פותחים PowerShell בתיקייה הזו, ומריצים: `.\setup.ps1`
2. ייפתח דפדפן לאישור Cloudflare ← **Allow**.
3. הסקריפט יבקש **קוד כניסה**: בוחרים קוד שקל לזכור (לפחות 8 תווים), ומקלידים אותו פעמיים.
4. מדביקים את מפתח Resend.
5. בסוף מופיעה הכתובת: `https://system-design-course.<השם-שלך>.workers.dev`

**ד. בפעם הראשונה באתר**
נכנסים לכתובת ← מזינים את הקוד ← ⚙️ הגדרות ← מגדירים מייל ושעה ← **שליחת מייל בדיקה** (כדאי לבדוק גם בספאם).

**החלפת קוד הכניסה:** `npm run change-code` (מנתק את כל הדפדפנים).

## עדכונים

```powershell
npm run check     # בדיקת תקינות התוכן (מונחים, שאלות, סימולציות)
npm run deploy    # העלאה מחדש
npm run dev       # הרצה מקומית ב-http://127.0.0.1:8787 (קוד כניסה מקומי בקובץ .dev.vars)
```

## מבנה התוכן

- `public/data/lessons/NN.js`: שיעור אחד לכל קובץ. מושג מהמילון כותבים `[[key]]` או `[[key|טקסט]]`.
- `public/data/glossary.js`: המילון.
- `public/js/widgets.js`: הסימולציות. משבצים בשיעור עם `<div class="widget" data-widget="name"></div>`.
- `src/worker.js`: ה-API והתזכורות.
